# Arena Fire

Браузерный многопользовательский 3D-шутер от первого лица в духе Crossfire: командный бой 4 на 4, боты заполняют пустые места. Вокруг игры — полноценный сайт: главная страница, регистрация и вход, лобби с комнатами и чатом, профиль со статистикой, уровни, магазин скинов, кланы и рейтинг.

**Стек:** Node.js + Express + Socket.io (сервер), PostgreSQL (аккаунты и прогресс), Three.js (клиент, low-poly). Всё в одном сервисе на Railway.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | главная: онлайн, статистика, лучшие игроки |
| `/register`, `/login` | регистрация и вход (email или позывной + пароль) |
| `/lobby` | быстрая игра, своя комната (публичная или приватная по коду), вход по коду, список комнат, чат |
| `/play` | сама игра (параметры из лобби: `mode`, `skill`, `room`, `code`) |
| `/profile`, `/profile/Ник` | уровень, звание, статистика, история матчей |
| `/shop` | скины оружия, броня, цвет трассеров |
| `/clans`, `/clan/ID` | список кланов, создание, состав, вступление, исключение |
| `/leaders` | рейтинг по уровню, убийствам, победам, хедшотам; рейтинг кланов |
| `/settings` | смена пароля, выход |

Гостем играть можно без регистрации (кнопка «Играть как гость»): прогресс при этом не сохраняется.

## Режимы и платформы

| Режим | Правила |
|---|---|
| Командный бой (`tdm`) | 4 на 4, побеждает команда, первой набравшая 40 убийств |
| Только хедшоты (`hs`) | Урон идёт только в голову, по телу почти не проходит. До 30 убийств |
| Каждый за себя (`ffa`) | Все против всех, до 20 убийств |
| Гонка вооружений (`gg`) | Каждое убийство даёт следующее оружие, нужно пройти все пять |

- Комнаты общие для ПК и телефона. У ника в бою значок: 🖥 с компьютера, 📱 с телефона (неймплейт, таблица счёта, лента убийств).
- ПК: мышь и клавиатура, без авто-огня и помощи прицеливания (для баланса). Телефон: стики, авто-огонь и лёгкая помощь прицеливания. На сайте эти детали не показываем.
- Платформа определяется автоматически (`pointer: coarse`), в настройках её можно сменить. Там же качество графики: низкое, среднее, высокое.
- Параметры адреса игры: `mode`, `skill`, `room`, `code`, `rn`, `priv`, `gm`.
- Картинка героя `public/img/soldier.svg` генерируется режимом `hero` в `test/preview/render.mjs`.

## Арена и окружение

Арена собрана из набора Kenney «Mini Arena» (CC0, www.kenney.nl): стены, колонны, статуи, баннеры, ворота, деревья. Исходные GLB превращены скриптом `tools/convert-kenney.py` в один файл `public/world/kit.json` (палитра запечена в цвета вершин, загрузчик GLTF не нужен). `public/world.js` расставляет детали по коллайдерам из `shared.js` и склеивает всё в один меш. Если набор не загрузился, показывается простой вид из коробок. Предпросмотр без браузера: `node test/preview/world-dump.mjs out.json && python3 test/preview/world-shot.py out.json out.png 0 38 -52 0 0 0 55`.

## Прогрессия

- За матч игрок получает **опыт и монеты** (убийства, хедшоты, победа; ушедшему посреди матча — меньше). Награду считает сервер, подделать её с клиента нельзя. Формулы — `public/catalog.js`.
- **Уровни** до 100, звания от новобранца до генерала. **Ежедневный бонус** растёт с серией дней.
- **Магазин:** 7 расцветок оружия, 6 комплектов брони, 6 цветов трассеров. Предметы закрыты уровнем и стоят монеты. Только внешний вид, на баланс не влияет. Скины видят и другие игроки.
- **Кланы:** создание стоит 500 монет, до 30 участников, тег показывается в игре и рейтинге.
- Один аккаунт — одно подключение к матчу.

## Запуск локально

```bash
npm install
npm start          # http://localhost:3000
npm test           # физика, серверная логика, хранилище, API, дымовой тест клиента
```

Без `DATABASE_URL` сайт работает на хранилище в памяти (данные пропадают при перезапуске). Для настоящей базы задайте `DATABASE_URL=postgres://...`.

## Деплой на Railway

1. Залейте папку в GitHub-репозиторий. Railway → **New Project → Deploy from GitHub repo**.
2. В проекте нажмите **New → Database → Add PostgreSQL**. Railway создаст базу.
3. Откройте сервис с игрой → **Variables** и добавьте:
   - `DATABASE_URL` — **Add Reference** → выберите базу Postgres → `DATABASE_URL`;
   - `SESSION_SECRET` — любая длинная случайная строка (например, 40 случайных символов). Без неё сессии сбрасываются при каждом перезапуске.
4. **Settings → Networking → Generate Domain** — адрес сайта.
5. После деплоя в логах должна быть строка `База данных: PostgreSQL`. Таблицы создаются автоматически при старте.

Если база недоступна, сайт покажет предупреждение «прогресс временно не сохраняется» и продолжит работать в памяти.

Другие переменные: `PGSSL=1` — включить SSL для внешних адресов базы.

> Комнаты хранятся в памяти процесса, поэтому держите **одну реплику** сервиса. Для масштабирования нужен sticky-routing или отдельный матчмейкер.

## Безопасность

- Пароли хранятся как scrypt-хеши с солью. Сессия — подписанная HttpOnly-кука (SameSite=Lax, Secure на https), смена пароля завершает старые сессии.
- Ограничение попыток входа и регистрации, проверка источника и типа запросов (защита от CSRF), экранирование всего пользовательского текста.
- Подтверждение email и восстановление пароля не реализованы (нет почтового сервиса). Вход через Google, Apple и Telegram не подключён: нужны ключи этих сервисов. Структура аккаунтов позволяет добавить их позже.

## Управление

| | Телефон | ПК |
|---|---|---|
| Движение | левый стик (появляется под пальцем) | WASD |
| Прицел | перетаскивание по правой части экрана | мышь (захват курсора по клику) |
| Огонь | кнопка 🔫 (можно одновременно водить пальцем) | ЛКМ |
| Прицеливание (ADS) | кнопка ◎ (нажать — вкл/выкл) | ПКМ (удерживать) |
| Прыжок / перезарядка | кнопки справа | Пробел / R |
| Оружие | панель внизу экрана | 1–5 или колесо |
| Таблица счёта | кнопка ≡ | Tab |

Оружие (5 видов): автомат, пистолет, дробовик, пистолет-пулемёт, снайперская винтовка. У каждого свои урон, скорострельность, разброс, отдача и звук. Попадание в голову наносит повышенный урон, урон падает с дистанцией.

**Зоны попадания.** Тело игрока состоит из трёх хитбоксов, повторяющих форму модели: голова, туловище (с руками и рюкзаком), ноги. Урон зависит от зоны: голова — множитель оружия (×1.5–2.5), туловище — полный урон, ноги — ×0.75. Зона попадания приходит с сервера: маркер попадания и число урона красные при попадании в голову, жёлтые — в ноги, белые — в туловище; звук тоже разный. Пуля, пролетевшая мимо узкого тела, не засчитывается. Параметры: `HITBOXES`, `ZONE_LEG_MULT` в `public/shared.js`.

**Авто-огонь.** Когда враг оказывается под прицелом (и виден, в пределах дальности оружия), игра стреляет сама — как в мобильных шутерах; пока прицел на цели, огонь идёт с темпом оружия, отвёл — прекратился. Снайперка стреляет сама только в оптике. Включается кнопкой «А» вверху экрана или галочкой в меню; на телефоне по умолчанию включён.

**Стрельба.**
- Прицеливание (ADS): точнее разброс, приближение, медленнее движение. У снайперки — оптический прицел.
- Разброс растёт от очереди («bloom»), прицел на экране показывает реальный разброс.
- Отдача подбрасывает прицел и частично возвращается после очереди; лёгкая тряска камеры.
- Трассеры, следы от пуль на стенах (с учётом направления поверхности), пыль и искры, кровь при попадании, вылетающие гильзы, дымок.
- Числа урона, маркер попадания, баннеры «В ГОЛОВУ!», «ДВОЙНОЕ УБИЙСТВО», серии убийств; в ленте убийств видно оружие и дистанцию.
- Звуки синтезируются в браузере: у каждого оружия свой выстрел с эхом арены, перезарядка по фазам, шаги, свист пуль рядом с головой, звуки попаданий.
- Модели: солдаты в шлеме с ПНВ, гарнитуре и очках, с бронежилетом, подсумками, рацией, рюкзаком, наколенниками, кобурой и ботинками; детализированное оружие (прицелы, цевья, магазины, рельсы). От первого лица видны руки в перчатках с пальцами, смена магазина, затвор, помпа. Геометрия собирается в `public/geo.js` и запекается в несколько мешей на модель (мало вызовов отрисовки).

**Просмотр моделей без браузера и WebGL:** `node --import ./test/preview/register.mjs test/preview/render.mjs out.svg players|guns|close|running|vm`, затем открыть SVG.

**Помощь прицеливания.** На телефоне выстрел слегка притягивается к видимому врагу, если он близко к центру экрана (конус ≈ 4.5°). На ПК помощь слабая. Прицел краснеет, когда враг под ним. Настройка: `ASSIST_ANGLE` и `ASSIST_PULL` в `game.js`.

**Сложность ботов** выбирается в лобби (лёгкие / средние / сложные). Комнаты у разной сложности раздельные. Параметры в таблице `BOT_SKILL` в `game.js`: здоровье, урон, разброс, время реакции, скорость поворота.

## Полный экран

- **Android Chrome и ПК:** при нажатии «В бой» или кнопки ⛶.
- **iPhone (Safari):** браузер не умеет полноэкранный режим для сайтов. Откройте адрес игры в Safari → «Поделиться» → «На экран “Домой”» и запускайте с иконки: панелей браузера не будет.

## Как это устроено

- **Авторитетный сервер**, 30 тиков/с. Клиент шлёт ввод (направление, углы, прыжок, огонь), сервер двигает игроков и считает попадания.
- **Предсказание на клиенте:** своё движение считается локально тем же кодом (`public/shared.js`), а по снапшоту сервера состояние откатывается и перепроигрывается по неподтверждённым вводам.
- **Интерполяция** чужих игроков с задержкой 100 мс.
- **Лаг-компенсация выстрелов:** сервер хранит секунду истории позиций и откатывает цели ко времени, которое видел стрелок (не более 350 мс).
- **Боты:** видят цель по линии обзора, реагируют с задержкой, стреляют очередями, ходят между точками маршрута и разворачиваются при застревании. Урон ботов снижен, у них больший разброс.
- **Матч:** до 40 убийств или 5 минут, затем 10 секунд итогов и новый матч. Возрождение через 3 секунды с 2 секундами защиты.

## Структура

```
server.js          HTTP, страницы, Socket.io, комнаты, награды
api.js             HTTP API: аккаунты, профиль, магазин, кланы, рейтинг
accounts.js        пароли (scrypt), сессии, ограничение попыток
db.js              хранилище: PostgreSQL и запасной вариант в памяти
game.js            Room / Player / боты / стрельба (без зависимостей)
public/catalog.js  уровни, награды, каталог магазина — общий код
public/shared.js   карта, оружие, физика, лучи — общий код сервера и клиента
public/*.html      страницы сайта; play.html — игра
public/site.css, site.js   стиль и общий код сайта
public/client.js   ввод, HUD, сеть, камера, цикл игры
public/models.js, guns.js, geo.js   модели игроков и оружия, построитель геометрии
public/fx.js, audio.js   эффекты и синтез звука
test/              тесты и инструменты предпросмотра
```

Предпросмотр сайта без установки пакетов: `node --import ./test/dev-register.mjs test/devserver.mjs 8099`, затем `python3 test/preview/site-shots.py папка 8099` (скриншоты всех страниц и проверка ошибок JavaScript).

## Настройка

Всё в `public/shared.js`:

- `MATCH` — лимит убийств, время матча, число ботов (`botsTotal`), максимум людей в комнате;
- `WEAPONS` — урон, скорострельность, магазин, разброс;
- `BOXES` — карта (стены, ящики, колонны). Ящики высотой 1 м можно перепрыгнуть;
- `PLAYER` — скорость, прыжок, гравитация.

## Ограничения

- Одна карта и пять видов оружия.
- Нет голосового чата и друзей; текстовый чат есть только в лобби.
- Рендер, звук и ощущение стрельбы не проверялись на реальных устройствах (тесты идут на заглушках WebGL/WebAudio): возможно, понадобится подбор освещения, громкости, чувствительности и расположения кнопок.
- Запросы к PostgreSQL проверены на локальной базе через тестовую обёртку; драйвер `pg` ставится при деплое (`npm install`).
