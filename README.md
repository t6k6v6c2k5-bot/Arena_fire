# Arena Fire

Многопользовательский 3D-шутер от первого лица для Telegram Mini App в духе Crossfire: командный бой 4 на 4, боты заполняют пустые слоты, поэтому играть можно и в одиночку.

**Стек:** Node.js + Express + Socket.io (сервер), Three.js (клиент, low-poly), всё в одном сервисе на Railway.

## Запуск локально

```bash
npm install
npm start          # http://localhost:3000
npm test           # физика, серверная логика, дымовой тест клиента
```

## Деплой на Railway

1. Залейте папку в GitHub-репозиторий.
2. Railway → **New Project → Deploy from GitHub repo**. Сборка и старт подхватываются из `package.json` и `railway.json`, healthcheck — `/health`.
3. Сервис → **Settings → Networking → Generate Domain**. Получите адрес вида `https://arena-fire-production.up.railway.app`.
4. Переменные окружения (всё необязательно):
   - `BOT_TOKEN` — токен бота; включает проверку подписи Telegram (ники берутся из Telegram и не подделываются).
   - `REQUIRE_TG=1` — пускать только через Telegram (нужен `BOT_TOKEN`). Без этого в игру можно зайти и из обычного браузера, удобно для тестов.

> Комнаты хранятся в памяти процесса, поэтому держите **одну реплику** сервиса. Для масштабирования нужен sticky-routing или отдельный матчмейкер.

## Подключение к Telegram-боту

В @BotFather:

- **Кнопка меню:** `/mybots` → ваш бот → *Bot Settings → Menu Button → Configure menu button* → вставьте URL с Railway.
- **Mini App:** `/newapp` → выберите бота → укажите URL с Railway. Ссылка вида `https://t.me/<бот>/<имя_app>`.

Играть лучше в **горизонтальной ориентации**. В вертикальной игра покажет подсказку повернуть телефон.

## Управление

| | Телефон | ПК |
|---|---|---|
| Движение | левый стик (появляется под пальцем) | WASD |
| Прицел | перетаскивание по правой части экрана | мышь (захват курсора по клику) |
| Огонь | кнопка 🔫 (можно одновременно водить пальцем) | ЛКМ |
| Прыжок / перезарядка / оружие | кнопки справа | Пробел / R / 1, 2, 3 или колесо |
| Таблица счёта | кнопка ≡ | Tab |

Оружие: автомат (авто), пистолет (одиночный), дробовик (8 дробин). Попадание в голову наносит повышенный урон.

## Как это устроено

- **Авторитетный сервер**, 30 тиков/с. Клиент шлёт ввод (направление, углы, прыжок, огонь), сервер двигает игроков и считает попадания.
- **Предсказание на клиенте:** своё движение считается локально тем же кодом (`public/shared.js`), а по снапшоту сервера состояние откатывается и перепроигрывается по неподтверждённым вводам.
- **Интерполяция** чужих игроков с задержкой 100 мс.
- **Лаг-компенсация выстрелов:** сервер хранит секунду истории позиций и откатывает цели ко времени, которое видел стрелок (не более 350 мс).
- **Боты:** видят цель по линии обзора, реагируют с задержкой, стреляют очередями, ходят между точками маршрута и разворачиваются при застревании. Урон ботов снижен, у них больший разброс.
- **Матч:** до 40 убийств или 5 минут, затем 10 секунд итогов и новый матч. Возрождение через 3 секунды с 2 секундами защиты.

## Структура

```
server.js          HTTP, Socket.io, комнаты
game.js            Room / Player / боты / стрельба (без зависимостей, покрыт тестами)
auth.js            проверка подписи Telegram initData
public/shared.js   карта, оружие, физика, лучи — общий код сервера и клиента
public/client.js   рендер, ввод, HUD, звук, сеть
test/              юнит-тесты и дымовой тест клиента
```

## Настройка

Всё в `public/shared.js`:

- `MATCH` — лимит убийств, время матча, число ботов (`botsTotal`), максимум людей в комнате;
- `WEAPONS` — урон, скорострельность, магазин, разброс;
- `BOXES` — карта (стены, ящики, колонны). Ящики высотой 1 м можно перепрыгнуть;
- `PLAYER` — скорость, прыжок, гравитация.

## Ограничения первой версии

- Одна карта и три вида оружия, без магазина и прокачки.
- Нет голосового и текстового чата.
- Рендер не тестировался на реальных устройствах: возможно, понадобится подбор освещения, чувствительности и расположения кнопок.
